Skill Required

  • Html
  • CSS
  • Javascript
  • Angular/React
  • Tailwind CSS
  • Git & GitHub

Step-By-Step Guid To Become Frontend Developer

  1. First Learn Fundamentals of how the web work(HTML & DNS
  2. Master HTML to structure your content and then learn CSS to style it effecitively
  3. Build Static clone of website like Amazon or Zomato using HTMl & CSS Only
  4. Learn Javascript add interactivity and create dynamic project like to-do-list or calculator.
  5. Get hand on exprience with essential tools like Git , Git-Hub,Typscript and Tailwind-CSS
  6. Finally,lear any framwork or library like (React or Angulat) to build advance ,complex project & learn how to deploy them
